# Car-Sales-Analysis
Description:

This car sales analysis is made totally in Microsoft Power BI Desktop.
The dataset is downloaded from Kaggle and it is reffered to car sales at United Sales.
I have created explicit DAX measures for all the metrics.
In the first dashboard there are analyzed some basic KPIs and the most important metrics. Then moving on a second level of granularity, there is a second dashboard dedicated to each car's overall performance.
The dataset was already cleaned and the modeling is simple, just one fact table and a calendar one.
In this project I focused more on embellisment tasks.
I hope you find it interesting!
